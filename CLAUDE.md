# Instruções para trabalhar neste repositório

- A planilha `Relacao de Expurgo para Rascunho.xlsx` pode ter colunas a mais além das que o script lê. Isso é intencional: são colunas visuais, usadas por quem está digitando os dados para facilitar a conferência manual. Não questione a existência de colunas adicionais nem sugira removê-las.
